## Projects

### 🦷 Brightside Dental: Dental Clinic
Clean, trustworthy design for a family dental practice.

- Online appointment request form with validation
- Animated statistics counters
- Auto-playing patient reviews slider
- FAQ accordion
- Sticky "Book Appointment" button on mobile
- Embedded Google Map

[View live demo](https://pudintq.github.io/portfolio/brightside-dental/) · [Source code](brightside-dental/)

### ☕ Ember & Oak: Coffee Shop
Warm, editorial design for an independent café and bakery.

- Tabbed menu (Coffee / Brunch / Bakery)
- Live "Open now / Closed" status based on opening hours
- Product cards with "Add to bag" notifications
- Animated SVG illustration and scrolling marquee
- Newsletter sign-up form

[View live demo](https://pudintq.github.io/portfolio/ember-oak-coffee/) · [Source code](ember-oak-coffee/)

---

### 💪 Ironclad Fitness: Gym
Bold, high-energy dark theme for a strength and conditioning gym.

- Interactive weekly class schedule with live spot availability
- Monthly / annual pricing toggle
- BMI calculator with visual result bar
- Coach profiles and testimonial section
- Free-trial sign-up form

[View live demo](https://pudintq.github.io/portfolio/ironclad-fitness/) · [Source code](ironclad-fitness/)

## Built With

- **HTML5**: semantic, accessible markup
- **CSS3**: Flexbox, Grid, custom properties and animations (no frameworks)
- **Vanilla JavaScript**: lightweight interactivity, no dependencies
- **Google Fonts**

### Every project includes
- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Fast loading with no heavy libraries
- ✅ Scroll-reveal animations, with respect for users' reduced-motion settings
- ✅ Mobile navigation menu
- ✅ Basic SEO (meta tags and semantic structure)
